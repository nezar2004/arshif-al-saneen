# أرشيف السنوات

مكتبة عربية لأسئلة السنوات السابقة. تتضمن البحث بالنص والمادة والسنة، وفلاتر القسم والمادة ونوع الامتحان، ولوحة لإدارة المحتوى. يبدأ الطالب من الصفحة الرئيسية ويسجّل الدخول برقمه الجامعي وكلمة مروره. إنشاء الحساب متاح من صفحة التسجيل. التسجيل يعتمد على البيانات التي يُدخلها الطالب ولا يتصل بنظام الجامعة أو بخدمة تحقق من البريد.

## تشغيل النسخة المحلية

ثبّت Node.js 24 أو أحدث، فك ضغط مجلد المشروع، ثم شغّل `npm start` من داخل المجلد. افتح `http://127.0.0.1:4173` للمكتبة أو `http://127.0.0.1:4173/admin` للإدارة. يطبع التشغيل مفتاح إدارة محليًا عشوائيًا لكل تشغيل، ويمكن تحديد مفتاح خاص في متغير البيئة `ADMIN_PASSWORD`. يحفظ التشغيل المحلي البيانات والملفات في المجلد `.data`. احتفظ بنسخة من هذا المجلد بعد إيقاف التشغيل لاسترجاع التجربة المحلية. التخزين المحلي مستقل عن تخزين الموقع المنشور.

## إضافة أسئلة السنوات

1. افتح لوحة الإدارة وسجّل الدخول بحساب مالك الموقع عند استخدام النسخة المنشورة.
2. أضف القسم ثم المادة.
3. أضف امتحانًا وحدد المادة والسنة والنوع (ميد أو فاينل أو ميك أب). يمكنك كتابة نص الأسئلة أو الملاحظات.
4. في قسم الملفات، اختر الامتحان وارفع ملفات PDF أو صور JPG أو PNG أو WebP. الحد لكل ملف ٢٠ م.ب.
5. افتح المكتبة وتحقق من ظهور الامتحان والملفات. تظهر التعديلات للطلاب عند تحديث الصفحة.

لحذف امتحان احذف مرفقاته أولًا. ولحذف مادة أو قسم احذف العناصر المرتبطة أولًا. لتحديث محتوى ملف ارفع النسخة الجديدة ثم احذف القديمة.

## الاستضافة

ينشئ `npm run build` ملف Cloudflare Worker في `dist/server/index.js`. تستخدم استضافة Sites الربط `DB` لقاعدة D1 و`BUCKET` لملفات R2. يبدأ مخطط البيانات من `drizzle/0000_archive.sql`. تضبط الاستضافة هوية المشرف بواسطة السر `SITES_ADMIN_EMAIL` وعناوين الهوية التي يضيفها وكيل Sites. عند نقل المصدر إلى مضيف آخر استخدم `ADMIN_PASSWORD` القوي من إعدادات الأسرار، واحذف دعم عناوين هوية Sites إذا لم يكن المضيف يحقنها بشكل موثوق. يمكن وضع سجل المصدر في مستودع GitHub خاص دون نقل ملفات الامتحانات أو إعدادات الأسرار إليه.
